# Unicode Dictionary

Remember, you can always look up how a symbol is input using your
editor. mvrnote

| Char           | Input               |
|----------------|---------------------|
| `λ`            | `\Gl` or `\lambda`  |
| `→`            | `\->` or `\to`      |
| `Π`            | `\Pi`               |
| `×`            | `\times`            |
| `Σ`            | `\GS` or `\Sigma`   |
| `∈`            | `\in`               |
| `ℕ`, `ℤ`, etc. | `\bN`, `\bZ`, etc.  |
| `₁`, `₂`, etc. | `\_1`, `\_2`, etc.  |
| `¹`, `²`, etc. | `\^1`, `\^2`, etc.  |
| `ᵃ`, `ᵇ`, etc. | `\^a`, `\^b`, etc.  |
| `⁻`            | `\^-`               |
| `·`            | `\cdot`             |
| `⊤`            | `\top`              |
| `∅`            | `\emptyset` or `\0` |
| `ℓ`            | `\ell`              |
| `∘`            | `\circ`             |
| `⊎`            | `\uplus`            |
| `¬`            | `\neg`              |
| `∀`            | `\all` or `\forall` |
| `∃`            | `\ex` or `\exists`  |
| `≡`            | `\==` or `\equiv`   |
| `≃`            | `\~-` or `\simeq`   |
| `∨`            | `\vee`              |
| `∧`            | `\wedge`            |
